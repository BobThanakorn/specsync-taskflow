# ADR-001: FastAPI + SQLite for TaskFlow

- Status: Accepted
- Date: 2026-09-25

## Context

TaskFlow needs a lightweight, self-hosted task management API that is quick to
develop and easy to run locally for small teams.

## Decision

- Use **FastAPI** (Python) for the API layer with Pydantic schemas.
- Use **SQLAlchemy** as the ORM.
- Use **SQLite** for storage in development and single-instance deployments.

## Consequences

- Single-file database keeps local setup trivial.
- FastAPI gives automatic OpenAPI documentation.
- If TaskFlow grows to multi-instance deployments, the database can be swapped
  for PostgreSQL without changing the API contracts.
